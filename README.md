# __rule__

print 1d2state3neighbor automata to your terminal


## installation

on mac (or linux with homebrew):

```bash
brew tap evapilotno17/__rule__
brew install rule
rule 88
```

on windows:

```bash
kys
```

## usage

randomly chosen rule, randomly chosen state

```bash
rule
```

specify rule (e.g. 110):

```bash
rule 110
```

specify rule and state width (in characters):

```bash
rule 30 100
```

## special rules

rule 110 - turing complete

rule 30 - psuedo rng

rule 11 - staircase
